## Possible Areas to Inspect

Use the following hints to guide your review. These are areas to look at, not confirmed findings.

- Controller authorization attributes — check which actions restrict by role and which rely only on authentication
- File upload validation — consider what checks are performed before a file is accepted and stored
- Logging statements — examine what business or user data appears in log messages
- Environment configuration — review what settings and values are present in development config files
- Error-handling behavior — consider what error information is exposed in different environments
